# 用量情景资料

periods 是八个完整的合成周期，days 保留 api 与 bytes 的同期路径；数值是非负十进制字符串。complete 是上游完整性标记。growth 的 factor 和 weight 是采购约定的情景参数。quotes 提供讨论用固定费、保底和阶梯，费用单位为同一合成币种的主单位，阶梯上界为空表示无上限，尚不是合同生效记录。

现有结算演练 fixtures/settlement.json 包含合同、核对、账单和审批操作。context 示例实际回放该演练，并检查周期日数据及情景权重的基本一致性，不修改合同费率。


每个周期覆盖 start_at 到 end_at 的完整 UTC 自然月，结束不包含。units 是 api 与 bytes 的计量单位，XTS 是合成币种。quotes.meters 为逐计量项阶梯；固定费先加到各项阶梯费用合计上，再应用整个周期的报价保底。增长倍数同时作用于各计量项用量，不能作用于固定费。
